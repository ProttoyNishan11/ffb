# 🎮 Family Feud – Bengali Edition  

A fun and interactive **Family Feud-style quiz game** built with **HTML, CSS, and JavaScript**.  
Each set contains 10 engaging questions with answers and points — perfect for playing with friends, family, or classmates!  

---
## 🌐 Live Demo

**Try it online:**
https://prottoynishan11.github.io/ffb/index.html

## 🧩 Features  
- 🎯 7 separate question sets (Set 1–7)  
- 📱 Fully responsive for mobile, tablet, and desktop  
- 🗂️ Clean layout with smooth animations  
- 🖋️ Uses **Kalpurush** font for Bangla text and **Arial Rounded MT Bold** for English  
- ✅ Click to reveal answers with interactive check marks  

---

## 💻 Technologies Used  
- **HTML5** for structure  
- **CSS3** for design and animations  
- **JavaScript (Vanilla)** for interactivity

## 🚀 How to Use  
1. **Download or clone** this repository  
2. Place all files in one folder  
3. Open `index.html` in your browser  
4. Click any **Set** to explore questions and play!
